# Product requirements

Product requirement documents (PRDs) for features that are planned but not yet built. Each PRD describes what a feature should do and why, not how to code it.

| PRD | Status |
|-----|--------|
| [Aircraft collection (dex)](aircraft-collection.md) | Draft |
| [Partial reveal mode](partial-reveal-mode.md) | Draft |

## Conventions

- One feature per file, named in kebab-case.
- Start with a status line: Draft, Approved, In progress, or Shipped.
- Keep open questions in their own section so they're easy to find and close.
